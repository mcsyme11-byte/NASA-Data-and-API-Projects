# Glossary

| Term | Meaning |
|---|---|
| **API** | Application programming interface: a web address a program asks for data, answered in a fixed format (usually JSON). |
| **API key** | A code that identifies who is asking an API. NASA's are free; a key is never written into this project's code. |
| **astronomical unit (au)** | The average distance from the Earth to the Sun, about 149.6 million km. |
| **CC BY 4.0, CC BY-SA 3.0 IGO** | Creative Commons licences: reuse is allowed with credit; "SA" (share-alike) means changed versions must use the same licence. ESA/Webb and ESA/Hubble pictures use CC BY 4.0; some other ESA material uses CC BY-SA 3.0 IGO. |
| **CDN** | Content delivery network: servers that hand out files (such as code libraries) quickly from near the visitor. |
| **close approach** | The moment an object passes nearest the Earth on its orbit, with its miss distance and speed. |
| **DEMO_KEY** | NASA's shared key for trying the APIs: 30 requests an hour and 50 a day per connection. |
| **EONET** | NASA's Earth Observatory Natural Event Tracker: wildfires, storms, volcanoes and other events as they happen. |
| **ESA** | The European Space Agency. |
| **force push** | Overwriting a branch's history on GitHub; blocked on this repository's `main`. |
| **GIBS** | NASA's Global Imagery Browse Services: daily satellite pictures of the whole Earth, delivered as map tiles. |
| **GitHub Actions** | Jobs GitHub runs by itself: the checks after every push, the daily data updates, and this record's rebuild. |
| **GitHub Pages** | GitHub's free web hosting, which publishes the site from the repository. |
| **Horizons** | NASA/JPL's service for the positions of planets, moons, asteroids and spacecraft at any time. |
| **LD (lunar distance)** | The average distance from the Earth to the Moon, about 384,400 km; used to make miss distances easy to picture. |
| **Ls (solar longitude)** | Where Mars is on its orbit, as an angle: the Martian season (0° is the start of northern spring). |
| **MIT License** | The licence of this project's own code and documents: anyone may use and change them, keeping the copyright notice. |
| **NEO** | Near-Earth object: an asteroid or comet whose orbit brings it within 1.3 au of the Sun at its closest, and so near the Earth's orbit. |
| **NEOCC** | ESA's NEO Coordination Centre, which keeps ESA's impact-risk list. |
| **NeoWs** | NASA's Near Earth Object Web Service, the API behind the Asteroid Tracker's weekly list. |
| **PDS** | NASA's Planetary Data System, the archive of data from planetary missions. |
| **potentially hazardous asteroid** | NASA's label for an asteroid larger than about 140 m whose orbit comes within 0.05 au of the Earth's. It describes a possibility, not a predicted impact. |
| **REMS** | Rover Environmental Monitoring Station: Curiosity's weather station on Mars. |
| **repository secret** | A value kept encrypted by GitHub for its jobs (such as a service key); never visible in the code or the site. |
| **Sentry** | NASA/JPL's impact-monitoring system and its list of objects with a possible future impact. |
| **sol** | A Martian day: 24 hours 39 minutes. |
